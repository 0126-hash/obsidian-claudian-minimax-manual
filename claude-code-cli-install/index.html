Claude Code CLI Guide

Claude Code CLI 安装说明

按顺序完成安装、验证和路径复制。后续在 Claudian 设置里找不到 Claude CLI 时，把这里查到的路径填进去。

适用：macOS / Linux / WSL / Windows 优先使用官方安装器 备用方式：npm 安装
准备 安装 验证 复制路径 常见问题

一、开始前准备

需要准备

  • 电脑可以正常访问 Claude Code 官方安装地址。
  • 如果使用 npm 备用安装，电脑需要 Node.js 18 或更高版本。
  • Windows 用户建议使用 PowerShell，不要用 Obsidian 内置终端或网页输入框。

先打开系统终端

  • macOS：打开“终端”。
  • Windows：打开“PowerShell”。
  • Linux / WSL：打开当前系统的终端。

二、安装 Claude Code CLI

使用官方安装器安装

选择你的电脑系统，复制对应命令到系统终端运行。

curl -fsSL https://claude.ai/install.sh | bash

安装完成后，关闭当前终端窗口，重新打开一个新终端。

irm https://claude.ai/install.ps1 | iex

安装完成后，关闭当前 PowerShell 窗口，重新打开一个新 PowerShell。

备用安装方式

如果官方安装器无法运行，再使用 npm 安装。不要在命令前加 sudo。

npm install -g @anthropic-ai/claude-code
如果提示 node 或 npm 找不到，先安装 Node.js 18 或更高版本，再回到这里重新运行 npm 安装命令。

三、验证是否安装成功

查看版本

在新打开的终端里运行：

claude --version
能看到版本号，说明命令已经安装到系统里。

启动 Claude Code CLI

继续运行：

claude

如果能进入 Claude Code CLI 的启动界面，说明安装成功。之后可以关闭终端，回到 Obsidian 配置 Claudian。

四、复制 Claude CLI 路径

只有 Claudian 找不到 Claude CLI 时才需要填写

如果 Claudian 没有报错，可以不填路径。只有设置页提示找不到 Claude CLI 时，再按下面方式复制路径。

运行下面这行命令。如果安装正确，终端会返回一行路径。复制你电脑上实际返回的那一行。

which claude

把返回路径填到 Claudian 设置里的 Claude → Setup → Claude CLI 路径。

运行下面这行命令。如果安装正确，PowerShell 会返回一行路径。复制你电脑上实际返回的那一行。

where.exe claude

把返回路径填到 Claudian 设置里的 Claude → Setup → Claude CLI 路径。

五、常见问题

提示 command not found

先关闭终端再重新打开。如果仍然不行，重新运行安装命令；npm 方式安装时，先确认 node --version 能返回 18 或更高版本。

npm 权限报错

不要使用 sudo npm install -g。优先改用官方安装器，或重新安装 Node.js 后再运行 npm 安装命令。

Windows 安装后仍找不到 claude

关闭 PowerShell 后重新打开，再运行 claude --version。如果仍找不到，重新运行 PowerShell 安装命令。

Claudian 里仍提示找不到 Claude CLI

用 which claude 或 where.exe claude 查到路径后，填到 Claude → Setup → Claude CLI 路径，保存后重启 Obsidian。
