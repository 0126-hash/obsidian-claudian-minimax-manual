模型：MiniMax-M2.7 协议：Anthropic-compatible
国内 Base URL https://api.minimaxi.com/anthropic

一、开始前准备

检查 Claude CLI 路径

先在系统终端确认 Claude Code CLI 是否可用。如果终端能返回 claude 路径，并且运行 claude 能打开 Claude Code CLI，就可以继续后面的配置。

如果终端提示 command not found，或 Windows 提示找不到文件，说明 Claude Code CLI 还没装好。先确认电脑已安装 Node.js 18 或更高版本，然后在终端运行 npm install -g @anthropic-ai/claude-code。安装完成后再运行 claude，能打开 Claude Code CLI 就说明安装成功。

运行下面这行命令。如果配置正确，会出现下一行这种路径：

which claude

复制返回的路径，例如 /usr/local/bin/claude。

运行下面这行命令。如果配置正确，会出现下一行这种路径：

where.exe claude

复制返回的路径，例如 C:\Users\你的用户名\AppData\Local\Programs\Claude\claude.exe。

需要准备

  • 已经安装并启用 Claudian 插件。
  • 已经安装 Claude Code CLI，并且在终端运行 claude 能打开。
  • 电脑上已安装 Node.js 18 或更高版本。
  • 已经拿到 MiniMax API Key。

二、在 Claudian 中填写 MiniMax 配置

打开 Claudian 设置页

先进入 Obsidian 的第三方插件管理页，再打开 Claudian 自己的设置页。

1
点击 Obsidian 左下角的 设置 齿轮。
2
在设置左侧栏选择 第三方插件。
3
在 已安装插件 里找到 Claudian，点击它右侧的齿轮按钮。

切换到 Claude 标签

MiniMax 要接入的是 Claude Code 兼容接口，所以这里配置 Claude 标签，不要填到 Codex 或 Opencode 标签里。

找到 Custom variables 输入框

继续向下滚动到 Claude → Environment。右侧有一个大文本框，名字叫 Custom variables。下一步会给你一整段配置，把它完整复制到这个文本框里，一行一条，不要拆开填写。

粘贴 MiniMax 配置

如果你使用国内 MiniMax 平台，直接复制下面这段，把 <你的 MiniMax API Key> 换成你自己的 Key。

ANTHROPIC_BASE_URL=https://api.minimaxi.com/anthropic
ANTHROPIC_AUTH_TOKEN=<你的 MiniMax API Key>
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
ANTHROPIC_MODEL=MiniMax-M2.7
ANTHROPIC_DEFAULT_SONNET_MODEL=MiniMax-M2.7
ANTHROPIC_DEFAULT_OPUS_MODEL=MiniMax-M2.7
ANTHROPIC_DEFAULT_HAIKU_MODEL=MiniMax-M2.7

保存配置

粘贴后点击输入框外，或切换到其他设置项，让 Claudian 保存配置。然后关闭当前 Claudian 聊天页，再重新打开。

三、验证是否成功

发送模型识别测试问题

打开 Claudian 聊天面板，发送下面这个问题。它会让模型说明自己和当前连接方式，方便判断是否真的走到了 MiniMax。

你是什么模型？请用一句话说明你的模型名称和当前 API 服务来源。

确认没有旧配置干扰

如果之前配置过 Anthropic、DeepSeek 或其他代理，把 Custom variables 里旧的 ANTHROPIC_ 配置整段替换掉，不要和 MiniMax 配置混在一起。

必要时用终端复核

如果你熟悉终端，可以用同一组环境变量启动 claude，然后在 Claude Code 里运行 /status 和 /model，确认 Base URL 指向 MiniMax，模型显示为 MiniMax-M2.7。

四、常见问题

提示 API Key 无效

确认使用的是 MiniMax API Key，并且填在 ANTHROPIC_AUTH_TOKEN 后面。MiniMax 这一路径不要写成 ANTHROPIC_API_KEY。

提示找不到 Claude CLI

如果还没安装，先运行 npm install -g @anthropic-ai/claude-code。安装后运行 claude 确认能打开，再把 which claude 或 where.exe claude 返回的路径填到 Claude → Setup → Claude CLI 路径。

仍然调用到旧模型

关闭当前 Claudian 会话，重新打开；如果仍不生效，重启 Obsidian。检查是否还有旧的 ANTHROPIC_BASE_URL 或 ANTHROPIC_MODEL 留在输入框里。

请求超时

先确认网络稳定。如果长任务频繁超时，可在 General → Environment → Shared environment 中单独加入 API_TIMEOUT_MS=3000000。不要把它和 MiniMax 的核心 ANTHROPIC_ 配置混在一起，避免 Claudian 显示环境变量归属提醒。
